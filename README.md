# Dashboard v1.0

Bu proje, basit bir haber ve hava durumu dashboard uygulamasıdır. Yazılım Mühendisliği dersi kapsamında Git kullanımını öğrenmek ve iş birliği yapmak amacıyla geliştirilmiştir.

## Özellikler

- **Hava Durumu:** Rastgele sıcaklık verisi üretir.
- **Haberler:** Güncel durum bilgisini getirir.

## Nasıl Çalıştırılır?

Projeyi çalıştırmak için terminale şu komutu yazın:

```bash
python main.py
```
